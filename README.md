# go1-sim

Симулятор Unitree Go1 в Webots с теми же ROS 2 топиками, что на настоящем роботе (`high_cmd`, `high_state`, `scan`). Программа, которая работает здесь, работает и на роботе, и наоборот: в обоих случаях это ноды `go1_control`.

Работает в Docker: Webots R2025a, ROS 2 Jazzy, MNN.

## Что внутри

| Путь | Что это |
|---|---|
| `Dockerfile` | образ: Ubuntu 24.04, ROS 2 Jazzy, Webots, MNN |
| `docker/run.sh` | запуск с ноутбука: открыть мир, выполнить команду или программу в контейнере |
| `docker/entrypoint.sh` | внутри контейнера: сборка пакетов, изоляция ROS, запуск команды |
| `worlds/` | `go1.wbt` (два ящика и стена), `level1.wbt` (уровень квалификации TrueTechArena с Go1) |
| `protos/` | `Go1.proto` (генерируется из URDF), `Wall.proto`, `Checkpoint.proto` |
| `controllers/go1_sim/` | контроллер робота: ROS-топики, `sport.py` (режимы Legged_sport), `locomotion.py` (ходьба) |
| `controllers/referee/` | судья уровня TrueTechArena (копия без изменений) |
| `config/level1.json` | настройки судьи для level1 |
| `go1_control/` | пакет управления, тот же код, что на роботе |
| `tools/make_proto.py` | делает `Go1.proto` из URDF |

Не входит в репозиторий:
- `policies/`: файлы политики ходьбы (`*.mnn`, `free_walk_export_cfg.json`). В TrueTechArena написано, что они извлечены из прошивки робота. Копировать из TrueTechArena (`1_tour/task-1/common/locomotion/policies/`) и не публиковать.
- `unitree_ws/`: клон `katie-hughes/unitree_ros2` (коммит `4763cb1`), нужен для сообщений и мешей Go1. Клонируй рядом с этим репозиторием.

## Раскладка папок

```
ROS2026/
├── go1_sim/        этот репозиторий
└── unitree_ws/     клон unitree_ros2 в src/unitree_ros2
```

Пути в `Go1.proto` идут относительно этой раскладки (`../../unitree_ws/...`). В контейнере та же раскладка: `/ws/go1_sim` и `/ws/unitree_ws`.

## Запуск

Нужны Docker и доступ к экрану (X11) для окна Webots.

```bash
cd ~/ROS2026/go1_sim
./docker/run.sh build        # первый раз, долго
./docker/run.sh              # открыть мир go1 (окно Webots)
```

В другом терминале:

```bash
./docker/run.sh run lidar_drive          # программа обхода препятствий
./docker/run.sh run main                 # программа из go1_control/main.py
./docker/run.sh exec ros2 topic list     # любая команда в окружении симулятора
./docker/run.sh exec ros2 topic echo --once /high_state
```

Уровень квалификации TrueTechArena с Go1:

```bash
./docker/run.sh level1
```

Результат судьи пишется в `controllers/referee/result.json` после финиша, падения или таймаута.

Остановить: Ctrl-C в окне, где запущен `./docker/run.sh`, или `docker stop go1-sim`.

## Изоляция от робота

Симулятор и всё, что запущено через `docker/run.sh`, работает на домене ROS 2 `42` и только внутри контейнера (`ROS_AUTOMATIC_DISCOVERY_RANGE=LOCALHOST`). Настоящий робот слушает домен `0` в `SSL_WIFI`, поэтому его не видно и не управляется.

Программы, которые запускаются на ноутбуке без `docker/run.sh`, попадают в домен `0`. Такие программы могут управлять настоящей собакой.

## Что совпадает с роботом

- Топики и типы: `high_cmd`, `high_state`, `scan` (как на `udp_high` и лидаре).
- `high_state` нулевой до первой команды и обновляется, только пока приходят `high_cmd`.
- Лидар: 921 луч, кадр `laser`, пустые лучи `100000`.
- Команды режимов `0`, `1`, `2`, `5`, `6`, `7` с теми же полями `HighCmd`.

## Чего нет и что отличается

- **Походка.** Ходит нейросетевой политикой, обученной для Go2 (длины ног у Go1 и Go2 одинаковые). Динамика, разгон и торможение не такие, как у `Legged_sport`.
- **Скорость.** Ошибка до 0,03 м/с и 0,1 рад/с после поправки `SPEED_OFFSET`.
- **Темп.** Симуляция идёт примерно на 0,83 от реального времени: `scan` около 8 Гц, `high_state` около 210 Гц.
- **Камер нет.** Топиков `/cam*` симулятор не публикует.
- **Лидар.** Положение на корпусе условное (центр, 0,10 м над `base`). Направление 0° совпадает с ROS (вперёд), на роботе не проверено.
- **`foot_force` нулевой**, заряд всегда 100.
- **Переходы.** Режимы, которые на роботе не проверялись (ходьба лёжа, встать сразу после демпфирования), симулятор отклоняет с предупреждением.

## Чем проверено

- `go1_control`: 26 тестов (`PYTHONPATH=. python3 -m pytest test` внутри пакета, с окружением ROS 2).
- Симулятор: `main.py` проходит в `go1` с кодом возврата 0, `lidar_drive` обходит ящик и проходит около 4 м.
- Судья `level1`: cp1–cp3 засчитываются при ходьбе.
- Docker-образ: собран и проверен только на ноутбуке разработчика; другие компьютеры не проверялись.

## Лицензия и публикация

В репозитории есть материалы из TrueTechArena (`worlds/level1.wbt`, `controllers/referee/`, `protos/Wall.proto`, `protos/Checkpoint.proto`, `protos/textures/`, `config/level1.json`). Их нельзя публиковать без разрешения авторов. Репозиторий держать приватным.
